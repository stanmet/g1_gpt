# GPT для G1

Голосовой помощник OpenAI для очков **Even Realities G1** и **iPhone**. Вы задаёте вопрос голосом, а ответ появляется текстом на дисплее очков. Помощник помнит разговор и понимает уточнения. Сервера нет: телефон сам обращается к OpenAI.

| | Приложение для iPhone — `ios-app/` (основное) | Мини‑приложение для Mentra — `mentra/` (запасное) |
|---|---|---|
| Как спросить | удерживать левую сенсорную панель и говорить | сказать «Вопрос, …» |
| Листание | тапы по панелям или автолистание | голосом: «дальше», «назад» |
| Микрофон | включён, только пока держите панель | включён постоянно |
| Установка | SideStore + бесплатный Apple ID; компьютер нужен один раз | через Mentra, компьютер не нужен |
| Обслуживание | продление раз в 7 дней — около минуты на iPhone | не нужно |

Приложение для iPhone сделано на основе официального демо Even Realities ([EvenDemoApp](https://github.com/even-realities/EvenDemoApp), BSD‑2‑Clause). Из демо взяты Bluetooth‑протокол G1, декодер звука LC3 и поток Even AI. Добавлено: OpenAI с контекстом разговора, поле «Обо мне», русский язык, вёрстка текста под шрифт G1, автоподключение и переподключение, хранение ключа в Keychain, журнал проверки.

## Установка приложения для iPhone

**Один раз на компьютере** (Windows, Mac или Linux, около 20 минут):
1. На iPhone должен быть задан код‑пароль. Подключите iPhone кабелем и нажмите «Доверять».
2. Установите [iloader](https://github.com/nab138/iloader). На Windows ещё нужен iTunes с сайта Apple.
3. В iloader войдите своим Apple ID (лучше отдельным) и выберите установку SideStore. Программа поставит SideStore и файл сопряжения.

**На iPhone:**
1. Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить и перезагрузить телефон.
2. Установите из App Store **LocalDevVPN**, откройте его и нажмите Connect.
3. В Safari откройте `https://github.com/stanmet/g1-gpt/releases/latest/download/GPT-G1.ipa`. Затем «Поделиться» → **SideStore**, или в SideStore нажмите «+» и выберите файл.
4. Освободите очки от других приложений: закройте Even и Mentra. Лучше отключить им Bluetooth: Настройки → Конфиденциальность → Bluetooth.
5. Откройте «GPT для G1» → «Найти очки» → нажмите на свою пару. В следующий раз приложение подключится само.
6. Вставьте ключ OpenAI API. Нажмите «Тест дисплея», затем «Спросить текстом» и задайте вопрос голосом.

**Раз в 7 дней:** LocalDevVPN → Connect → SideStore → **Refresh All**.

Новые версии собираются автоматически при каждом изменении в `ios-app/` и выкладываются в [Releases](../../releases). Установка — тем же способом, что в шаге 3.

## Проверка всей цепочки

Шаги ниже совпадают с записями в «Журнале проверки» приложения:

1. `[ble] Очки подключены` — связь с обеими дужками.
2. `[touch] Удержание левой панели` → `[voice] Микрофон очков включён`.
3. `[stt] <ваш вопрос>` — речь распознана.
4. `[openai] Ответ за N с` — получен ответ.
5. `[display] Первый экран показан на очках` — текст на дисплее.
6. Уточняющий вопрос: в записи `[ask] … (контекст: 2 сообщ.)` число больше нуля.

## Не проверено на устройстве (проверим вместе)

- Работа при заблокированном телефоне в кармане. Включён фоновый режим `bluetooth-central`, iOS сама переподключает очки.
- Качество распознавания русского. Если модель на телефоне не установлена, iOS использует серверы Apple.
- Ширина строки для кириллицы. Если строки переносятся сами, уменьшите «Ширину строки» в настройках; если остаётся много места — увеличьте.
- Keychain при бесплатной подписи. Если он недоступен, ключ хранится в данных приложения.

Аккаунт и память ChatGPT через API недоступны. Вместо этого используется поле «Обо мне». Можно спросить ChatGPT «Что ты обо мне помнишь? Выведи списком» и вставить ответ туда.

## Структура

- `ios-app/` — приложение на Flutter. Изменённые файлы: `lib/services/{evenai,openai_service,settings,g1_text}.dart`, `lib/ble_manager.dart`, `lib/views/home_page.dart`, `ios/Runner/{AppDelegate,BluetoothManager,SpeechStreamRecognizer}.swift`.
- `.github/workflows/ios.yml` — сборка неподписанного IPA на macOS и публикация в Releases.
- `mentra/` — мини‑приложение для Mentra с собственными тестами (`bun test tests`). Его страница установки лежит в `docs/` (GitHub Pages).
