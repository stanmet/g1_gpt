# EVA-IA

Голосовой помощник для очков **Even Realities G1** и **iPhone**. Работает как мини‑приложение для **Mentra** (`mentra/`): вы говорите, ответ появляется текстом на дисплее очков. Сервера нет — телефон сам обращается к выбранной нейросети. Ключи, настройки и история хранятся только на телефоне.

Что умеет (версия 1.12.0):

- **Помощник.** «Вопрос, …» — ответ на очках, помнит разговор и уточнения, отвечает на языке вопроса (русский или английский). Длинные ответы листаются голосом («дальше», «назад»), взглядом вверх или Bluetooth‑пультом, пока приложение открыто на телефоне.
- **Три нейросети.** ChatGPT, Claude или Gemini; «Клод, …» — спросить конкретную, «Переключись на Клода» — сделать основной.
- **Перевод.** «Транслейт» — речь вокруг переводится на очки (делает Mentra, ключ не нужен).
- **Слово или фраза на другом языке.** «Как будет на английском стол?» — на очках «стол → table», без активатора, в помощнике, лекции и беседе. Также «как по-английски …», «переведи … на английский», «по-немецки», «по-французски»; можно сделать паузу и сказать слово следом.
- **Лекция.** «Лекция» — тезисы речи лектора примерно раз в 15 секунд и сразу ответ, когда лектор спрашивает аудиторию. Конспект сохраняется на телефоне.
- **Беседа.** «Беседа» — ответ на вопросы с фактами, подсказка, когда вы запнулись («Императив — это…»), автор и источник прозвучавшей цитаты («Как говорил Черчилль, …», «Как говорится, …»), и подсказки по ходу разговора («Факт», «Ответ», «Спроси», «Скажи», «Цитата») к заданной цели.

Экран приложения: вкладки «Очки» (состояние, зеркало дисплея, режимы), «Разговор» и «Настройки» с разделами; голосовые команды — «Очки» → «Голосовые команды», журнал — «Настройки» → «Журнал».

**«Только мой голос» (эксперимент, Настройки → Голос).** Узнать голос владельца, как Siri, мини‑приложение не может: Mentra не даёт «отпечаток голоса», а запустить модель распознавания голоса в фоне Mentra нельзя. Но распознавание Mentra различает голоса внутри разговора («голос 1», «голос 2» — видно в «Журнале»). Приложение запоминает голос того, кто сказал активатор, и с включённой настройкой команды без активатора принимает только от него; чужая речь по‑прежнему идёт в лекцию и подсказки беседы, активатор работает всегда. Если в «Журнале» у фраз нет пометки «голос N», Mentra голоса не различает и настройка ничего не меняет. Ещё одна защита от случайных срабатываний — редкое слово в «Активаторах».

## Установка (без компьютера)

1. Установите **Mentra** из App Store, войдите и подключите G1.
2. Mentra → Settings → Miniapp Developer Settings → **Load Miniapp from URL** → вставьте `https://stanmet.github.io/g1_gpt` → Load Miniapp → разрешите микрофон. Либо откройте https://stanmet.github.io/g1_gpt/ на другом экране и отсканируйте QR через **Scan Miniapp QR Code**.
3. Откройте плитку «EVA-IA» → Настройки → Ключи API → вставьте ключ (таблица ниже).
4. «Проверить дисплей», затем скажите в очки: «Вопрос, …».

Новые версии Mentra подхватывает при перезапуске; версия видна в «Журнале» («Запущено, версия …»).

## Нейросети и расходы

| | Где взять ключ | Модели | Цена |
|---|---|---|---|
| ChatGPT (OpenAI) | platform.openai.com → API keys | GPT‑6.1 Terra, 6 Luna, 6.1 Sol, 6 Astra | Terra ≈ $0.002–0.005 за вопрос |
| Claude (Anthropic) | platform.claude.com/settings/keys → Create key, выбрать Workspace | Haiku 5.5, Sonnet 5.5, Opus 5.5, Fable 5.1 | Haiku от $0.10/$0.50 за 1 млн токенов |
| Gemini (Google) | aistudio.google.com/apikey → Create API key | 3.8 Flash, 3.5 Flash‑Lite, 4 Argon | есть бесплатный лимит запросов |

API оплачивается отдельно от подписок ChatGPT Plus или Claude Pro. Распознавание речи и перевод делает Mentra, для пользователя бесплатно.

Режимы «Лекция» и «Беседа» обращаются к нейросети часто: при настройках по умолчанию до ~240 (лекция) и ~360 (беседа) коротких запросов в час. На Claude Haiku или Gemini Flash это центы, на ChatGPT — дороже. Частота меняется в Настройках.

Аккаунт и память ChatGPT через API недоступны. Вместо памяти — поле «Обо мне»: можно спросить ChatGPT «Что ты обо мне помнишь? Выведи списком» и вставить ответ туда.

## Особенности Mentra и G1

- **Панель Mentra.** Пока Mentra считает, что голова поднята, и включён её Contextual Dashboard, в очках видна панель Mentra (время, дата, заряд), а ответы приложения не показываются. Приложение предупреждает об этом. Решение: опустить голову; если панель не уходит — Mentra → Settings → Dashboard → выключить Contextual Dashboard или увеличить Adjust Head-Up Angle.
- **Сенсорные панели G1** Mentra на iPhone приложениям не передаёт; вместо них — голос, взгляд вверх или пульт‑клавиатура.
- **Микрофон G1** рассчитан на голос владельца. Если лектор или собеседник далеко: Mentra → Settings → Microphone → Preferred microphone → Phone.
- **Буквы й и ё** очки показывают как и и е (так делает Mentra для шрифта G1).
- **Хранилище.** Mentra 3.2.1 на iOS возвращает пустое значение для JSON в localStorage, поэтому приложение добавляет к записям префикс `~g1:` (с версии 1.5.1).

## Структура

- `mentra/` — мини‑приложение: `src/background/` (логика, режимы, нейросети), `src/ui/` (экран на телефоне), `tests/` (`bun test tests`, включая прогон собранного бандла в симуляции Mentra). Сборка: `bun run build.ts`; страница установки копируется в `docs/` (GitHub Pages).
- `ios-app/` — ранняя отдельная версия на Flutter на основе официального демо Even Realities ([EvenDemoApp](https://github.com/even-realities/EvenDemoApp), BSD‑2‑Clause): спрашивать удержанием левой панели, листать тапами. Только ChatGPT, без перевода, лекций и беседы. Ставится через SideStore (нужен компьютер один раз, продление раз в 7 дней). `.github/workflows/ios.yml` собирает неподписанный IPA в Releases при изменениях в `ios-app/`.
