GPT для G1

Мини‑приложение для Mentra: голосовой помощник для очков Even Realities G1 — ChatGPT, Claude или Gemini, перевод речи, тезисы лекций и подсказки в разговоре.

Способ 1 — только iPhone

  1. Скопируйте адрес: …
  2. Откройте приложение Mentra → Settings → Miniapp Developer Settings → Load Miniapp from URL.
  3. Вставьте адрес и нажмите Load Miniapp, разрешите микрофон.

В этом режиме Mentra загружает приложение с этой страницы при каждом запуске и сохраняет копию на случай отсутствия связи.

Способ 2 — QR с другого экрана

Откройте эту страницу на компьютере, планшете или другом телефоне. На iPhone: Mentra → Settings → Miniapp Developer Settings → Scan Miniapp QR Code и наведите камеру.

Так приложение устанавливается в телефон целиком и работает без этой страницы.

После установки

  1. Откройте плитку «GPT для G1» в Mentra: Настройки → Ключи API → вставьте ключ ChatGPT, Claude или Gemini. Ключ хранится только на телефоне.
  2. Нажмите «Проверить дисплей», затем спросите что‑нибудь текстом на вкладке «Разговор».
  3. Скажите в очки: «Вопрос, …». Листайте голосом: «дальше», «назад». Все команды — на вкладке «Очки».
