# GPT для G1

Голосовой помощник OpenAI для очков **Even Realities G1** на **iPhone**. Вы говорите вопрос в микрофон очков, ответ появляется текстом на дисплее. Помощник помнит разговор и понимает уточнения. Серверов нет.

```
голос → микрофон G1 → Mentra (распознавание ru‑RU) → мини‑приложение → OpenAI API → текст на G1
```

- **Mentra** (бесплатное приложение из App Store) — мост между iPhone и G1. Мини‑приложение работает внутри него, прямо на телефоне.
- **OpenAI** вызывается напрямую с телефона. Ключ хранится только в мини‑приложении на телефоне.
- **GitHub Pages** раздаёт файлы установки (папка `docs/`). Хостинг бесплатный.

## Установка

Страница установки: `https://<ваш-логин>.github.io/g1_gpt/`.

**Только iPhone.** Mentra → Settings → Miniapp Developer Settings → **Load Miniapp from URL** → вставить адрес страницы установки → Load Miniapp → разрешить микрофон.

**QR с другого экрана.** Откройте страницу установки на любом другом экране. В Mentra: Settings → Miniapp Developer Settings → **Scan Miniapp QR Code**. Приложение установится целиком и будет работать без страницы.

**После установки.** Откройте плитку «GPT для G1» и вставьте ключ OpenAI API (`platform.openai.com` → API keys). Затем: «Тест дисплея» → «Спросить текстом» → голосом.

## Как говорить

| Фраза | Действие |
|---|---|
| «Вопрос, …» / «Ассистент, …» / «Чат GPT, …» | задать вопрос (пауза ~1,5 с — конец вопроса) |
| «дальше», «назад», «сначала», «повтори» | листать ответ |
| «скрой» | убрать текст с дисплея |
| «стоп» | отменить вопрос, на который ещё не пришёл ответ |
| «новый разговор» | забыть контекст |

Касания тачпада G1 в Mentra на iOS (3.2.1) до мини‑приложений не доходят. Поэтому основное управление — голосом. Обработчики касаний встроены и заработают, если Mentra начнёт их передавать.

## Ограничения

- **Аккаунт и память ChatGPT** через API недоступны: API и ChatGPT — разные продукты. Замена — поле «Обо мне» и собственная история диалога. Совет: спросите ChatGPT «Что ты обо мне помнишь? Выведи списком» и вставьте ответ в поле «Обо мне».
- **Буквы й и ё.** В Mentra 3.2.1 для iOS драйвер G1 убирает диакритику, поэтому они могут выглядеть как «и» и «е». В коде следующей версии Mentra (3.3.0) это исправлено. Сам шрифт G1 эти буквы содержит.
- **Микрофон.** Пока мини‑приложение запущено, микрофон очков включён постоянно, а это расходует батарею. Остановить приложение можно с главного экрана Mentra или режимом «Выключен» в настройках.
- **Распространение.** Mentra 3.x пока не публикует мини‑приложения в своём каталоге. Установка — через инструменты разработчика (см. выше).

## Сборка

Компьютер пользователю не нужен: сборка делается в облаке, результат лежит в `docs/`. Чтобы пересобрать вручную, нужен [Bun](https://bun.sh):

```sh
bun run build.ts                       # → site/ (копируется в docs/)
bun test tests                         # 51 тест, включая прогон собранного бандла в «голой» JS‑среде
```

- `src/background/` — логика на телефоне: распознавание, активатор, OpenAI, листание.
- `src/ui/` — экран настроек и журнал проверки.
- `vendor/` — исходники Mentra Miniapp SDK 3.2.1 (Apache‑2.0, `github.com/Mentra-Community/MentraOS`), eventemitter3 (MIT) и qrcode‑generator (MIT).
